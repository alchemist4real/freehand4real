# freehand4real

Clean, white, symmetrical gesture controller for Chromium browsers (Chrome & Edge).
Built with Times New Roman typography, zero overflow layout, and short simple English.

---

## What's New in v1.1

- **Floating Window**: Draggable, compact, studio-grade on-screen floating window featuring:
  - Live webcam view with real-time hand skeleton overlay.
  - **Active Gesture Indicator**: High-contrast, prominent live badge that instantly displays the currently active gesture (e.g., `[ 👊 Fist: Scroll Up ]`, `[ ☝ Key A ]`, `[ 🤏 Pinch Click ]`).
  - Minimalist monochrome SVG icons matching the Times New Roman clean white aesthetic.
  - Symmetrical compact keypad with buttons `[A] [B] [C] [D] [E]` and `[◀ Left] [▲ Up] [▼ Down] [Right ▶]`.
- **Fist Scrolling (Tangan Menggenggam)**:
  - Simply make a fist (`👊`) to scroll!
  - Move your fist slightly **Up** ➔ **Scroll Up**.
  - Move your fist slightly **Down** ➔ **Scroll Down**.
  - Hold fist steady ➔ Neutral deadzone, no accidental scrolling.
  - Completely eliminates collision with open-hand finger counting!
- **Active Tab Multi-Tab Control**:
  - Automatically broadcasts actions to whatever tab is currently active.
  - Also includes Chrome **Side Panel** (`sidepanel.html`) accessible via one click from the extension popup.
- **Kill Switches & Visibility Controls**:
  - Close floating window anytime using the **`✕`** button on top-right of window header.
  - Close minimized bubble using the **`✕`** badge on top-right of bubble.
  - Full **Master Extension Switch** and **Floating Window Switch** available in the extension popup menu.
- **Bulletproof Option Selection**:
  - Automatically clicks and checks radio buttons and option choices on Moodle, Google Forms, Canvas, Quizizz, CAT/CBT exams, and React/Vue platforms.

## Gesture Cheat Sheet

| Gesture | Action | Description |
| :--- | :--- | :--- |
| 👊 **Fist Raised** | **Scroll Up** | Clench hand into a fist and move slightly up |
| 👊 **Fist Lowered** | **Scroll Down** | Clench hand into a fist and move slightly down |
| ☝️ **1 Finger** | **Key A** | Naturally extend index finger |
| ✌️ **2 Fingers** | **Key B** | Peace / V sign |
| 🤟 **3 Fingers** | **Key C** | 3 fingers extended |
| 🖖 **4 Fingers** | **Key D** | 4 fingers extended |
| 🖐️ **5 Fingers** | **Key E** | Open relaxed palm |
| 👈 **Point Left** | **Arrow Left** | Index pointed left (Prev question) |
| 👉 **Point Right** | **Arrow Right** | Index pointed right (Next question) |
| 👆 **Index Move** | **Air Cursor** | Laser cursor follows index fingertip |
| 🤏 **Pinch** | **Click** | Tap thumb and index finger together |

## How to Reload / Install

1. Open `chrome://extensions/` or `edge://extensions/`.
2. Click the **Reload (↺)** icon on the `freehand4real` card.
3. Open any website or [test.html](file:///C:/Users/ACER/Downloads/freehand4real/test.html) to try the floating window and fist scrolling!
